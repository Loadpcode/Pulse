XRay Pulse

XRay Pulse — Android-приложение для удобного управления VPN-подключением на базе Xray-core.

Основная идея проекта — сделать работу с VPN понятной даже для пользователей, которые не знакомы с сетевыми технологиями и не хотят разбираться в сложных настройках. Интерфейс построен так, чтобы основные функции были доступны в несколько нажатий, а дополнительные параметры оставались под рукой для тех, кому они нужны.

✨ Особенности

- Простой интерфейс — минималистичный дизайн и удобное управление подключением.
- Material Design 3 — современный интерфейс в стиле приложений Google.
- Поддержка тем оформления — тёмная, светлая и системная темы.
- Динамические цвета — адаптация цветовой палитры под оформление устройства на Android 12+.
- Персонализация — настройка цветов, формы и внешнего вида основной кнопки подключения.
- Управление профилями — добавление и обновление конфигураций.
- Контроль трафика — отображение использованного объёма, лимита и срока действия подписки.
- Дополнительные сетевые настройки — TLS Fragmentation, Mux, LAN, MTU, IPv6 и маршрутизация.
- Диагностика — просмотр журналов Xray и предварительный просмотр итоговой JSON-конфигурации.

🛠 Технологии

- Kotlin — основной язык разработки.
- Xray-core — ядро для работы VPN.
- Material Design 3 — основа визуального оформления.
- AAR-библиотека — сторонняя библиотека, используемая в проекте.
- Google AI Studio и Mistral AI — инструменты, использованные в процессе разработки.

🎨 Дизайн

Визуальная часть приложения следует принципам Material Design 3. Основное внимание уделено читаемости, простоте навигации и согласованности элементов интерфейса.

Пользователь может оставить стандартное оформление или настроить внешний вид приложения под свои предпочтения.

🎯 Цель проекта

Создать лёгкий и понятный инструмент для повседневного использования VPN, который не перегружает пользователя техническими деталями, но при этом предоставляет доступ к расширенным настройкам для более опытных пользователей.

XRay Pulse — управление VPN без лишней сложности.
