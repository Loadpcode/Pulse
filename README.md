
# XRay Pulse

**XRay Pulse** — Android-приложение для удобного управления VPN-подключением на базе Xray-core.

Основная цель проекта — сделать использование VPN понятным даже для людей, которые не знакомы с сетевыми технологиями и не хотят разбираться в сложных настройках.

Интерфейс разработан с упором на простоту, удобство и доступность основных функций. При этом приложение сохраняет возможность тонкой настройки для более опытных пользователей.

## ✨ Особенности

- **Простой интерфейс** — минималистичный дизайн и удобное управление VPN-подключением.
- **Material Design 3** — современный интерфейс в стиле приложений Google.
- **Поддержка тем оформления** — тёмная, светлая и системная темы.
- **Динамические цвета** — адаптация цветовой палитры под оформление устройства (Android 12+).
- **Персонализация** — настройка цвета, формы и внешнего вида основной кнопки подключения.
- **Управление профилями** — добавление и обновление конфигураций.
- **Контроль трафика** — отображение использованного объёма, лимита и срока действия подписки.
- **Сетевые настройки** — TLS Fragmentation, Mux, LAN, MTU, IPv6 и маршрутизация.
- **Диагностика** — просмотр журналов Xray и предварительный просмотр итоговой JSON-конфигурации.

## 🛠 Технологии

- **Kotlin** — основной язык разработки.
- **Xray-core** — ядро для работы VPN.
- **Material Design 3** — основа визуального оформления.
- **AAR-библиотека** — сторонняя библиотека, используемая в проекте.
- **Google AI Studio** — инструмент, использованный при разработке приложения.
- **Mistral AI** — использовался в процессе компиляции и разработки проекта.

## 🎨 Дизайн

Визуальная часть приложения построена на принципах Material Design 3 и во многом вдохновлена дизайном приложений Google.

Основное внимание уделено читаемости, простоте навигации и согласованности элементов интерфейса.

Пользователь может оставить стандартное оформление или настроить внешний вид приложения под свои предпочтения.

## 🎯 Цель проекта

Создать лёгкий и понятный инструмент для повседневного использования VPN, который не перегружает пользователя техническими деталями, но при этом предоставляет доступ к дополнительным настройкам.

Проект создаётся с упором на простоту использования, современный дизайн и возможность персонализации.
